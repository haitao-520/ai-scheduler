# 前端应用

前端应用是排班日历的全部界面层，由 React 组件与全局样式构成。它持有应用状态，编排日历、AI 对话、单日编辑与设置四类界面，并把状态变化同步到本地存储和小部件。

## 结构

```
src/
├── main.tsx              # React 挂载入口
├── App.tsx               # 顶层状态与浮层编排
├── styles.css            # 全局样式（设计系统）
├── types.ts              # 领域类型与默认值
└── components/
    ├── Calendar.tsx      # 日历、切月手势、下拉展开
    ├── ChatPanel.tsx     # AI 对话面板
    ├── DayEditor.tsx     # 单日班次编辑弹层
    ├── SettingsModal.tsx # 设置弹层
    └── TimeWheel.tsx     # 时/分滚轮
```

## 关键文件

| 文件 | 目的 |
|------|------|
| `App.tsx` | 状态中枢：排班、设置、对话、月份、浮层；AI 请求编排；小部件同步 |
| `Calendar.tsx` | 三面板横向轨道实现切月与下拉展开，渲染日期格与班次 |
| `ChatPanel.tsx` | 消息列表、深度思考折叠、图片选择与预览、输入发送 |
| `DayEditor.tsx` | 查看/删除当日班次，新增时间班次或休息 |
| `SettingsModal.tsx` | 配置 API Key、接口地址、模型、深度思考与强度 |
| `TimeWheel.tsx` | 原生滚动手感的时/分选择器 |
| `styles.css` | 全部视觉样式与 CSS 变量主题 |
| `types.ts` | `Shift`、`DayShifts`、`Settings`、`ChatMessage`、`ScheduleOp`、`AiResult` |

## 状态与数据流

`App.tsx` 是唯一的状态持有者，子组件通过 props 接收数据与回调：

- `shifts`：`DayShifts`，来自 `loadShifts`，变化时写回并同步小部件
- `settings`：`Settings`，来自 `loadSettings`
- `messages`：`ChatMessage[]`，来自 `loadChat`
- `month` / `selectedDay` / `chatOpen` / `settingsOpen`：仅界面状态

浮层（对话、设置）通过 `overlayStack` 与 `window.history` 关联：打开时 `pushState`，关闭时 `history.back()`，`popstate` 时弹出栈顶并关闭，从而让安卓返回键按后进先出关闭浮层。

## 规范

### 文件命名

- 组件：PascalCase `.tsx`，一个文件一个组件
- 逻辑：camelCase `.ts`（位于 `src/lib/`）
- 类型：集中在 `src/types.ts`

### 代码模式

组件均为函数组件，使用 Hooks 管理局部状态，父组件通过回调下发变更：

```tsx
interface DayEditorProps {
  date: Date
  shifts: Shift[]
  onClose: () => void
  onChange: (shifts: Shift[]) => void
}
```

受控更新的典型写法：子组件调用 `onChange`，由 `App.tsx` 更新 `shifts`，再经 `useEffect` 落盘与同步。

### 错误处理

- AI 请求错误由 `App.tsx` 捕获，存入 `error` 状态并展示在对话面板
- 图片读取失败在 `ChatPanel` 本地提示
- 设置保存后延迟 400ms 关闭，给出反馈

### 测试

项目未配置前端测试框架与测试脚本。

## 添加新组件

1. 在 `src/components/` 按 PascalCase 创建文件
2. 用 props 定义输入与回调，不在组件内直接读写 `localStorage`
3. 在 `App.tsx` 中引入并连接状态
4. 如需成为可返回关闭的浮层，在 `overlayStack`、`openOverlay`、`closeOverlay` 与 `popstate` 处理中同步添加
