安装步骤

  1. 点击上方按钮下载 APK
  2. 在手机「设置 - 安全」中允许安装未知来源应用
  3. 打开下载好的 APK 完成安装
  4. 打开 App，点击「AI 排班」，在右上角「设置」中填入 DeepSeek API Key

首次安装若提示「未知来源」，选择允许即可。API Key 仅保存在本机，不会上传。
